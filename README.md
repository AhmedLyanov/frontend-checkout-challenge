# Frontend Checkout Challenge

Frontend-приложение для checkout-сценария: каталог товаров, корзина, оформление заказа и оплата.

Проект реализован на React + TypeScript + Vite и работает с предоставленным API.

## Реализовано

- просмотр каталога товаров;
- добавление товаров в корзину;
- изменение количества товаров;
- удаление товаров из корзины;
- оформление заказа;
- выбор способа доставки:
  - самовывоз;
  - курьерская доставка;
- получение стоимости доставки через API;
- ввод данных покупателя;
- выбор способа оплаты:
  - банковская карта;
  - наличные;
- тестовая симуляция оплаты картой;
- обработка успешной оплаты, отказа и отмены;
- повторная попытка оплаты после неуспешной попытки;
- защита создания заказа и платежа с помощью `Idempotency-Key`;
- восстановление сессии и незавершённого checkout после перезагрузки страницы;
- обработка API, сетевых и ошибок разбора ответа;
- адаптивный интерфейс.

## Стек

- React 19
- TypeScript
- Vite
- React Router
- React Hook Form
- Zod
- Axios
- Tailwind CSS
- npm Workspaces
